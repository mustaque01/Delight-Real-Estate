# Delight Real Estate 🏡

A modern, responsive real estate website built with Next.js 16, React 19, and Tailwind CSS 4. This project showcases property services with a beautiful UI using Radix UI components and shadcn/ui.

## ✨ Features

- **Modern Tech Stack**: Built with Next.js 16 and React 19
- **Responsive Design**: Fully responsive layout that works on all devices
- **Beautiful UI**: Custom components built with Radix UI and shadcn/ui
- **Type-Safe**: Written in TypeScript for better developer experience
- **Dark Mode**: Theme support with next-themes
- **Performance**: Optimized for speed and SEO
- **Analytics**: Integrated with Vercel Analytics

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/)
- **UI Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **UI Components**: [Radix UI](https://www.radix-ui.com/) + [shadcn/ui](https://ui.shadcn.com/)
- **Form Handling**: React Hook Form with Zod validation
- **Icons**: Lucide React
- **Package Manager**: pnpm
- **Language**: TypeScript

## 📦 Key Dependencies

- **UI Components**: Comprehensive set of Radix UI primitives
- **Forms**: React Hook Form with Zod resolvers
- **Theming**: next-themes for dark mode support
- **Charts**: Recharts for data visualization
- **Carousel**: Embla Carousel
- **Notifications**: Sonner for toast notifications
- **Analytics**: Vercel Analytics

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ 
- pnpm (recommended) or npm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/mustaque01/Delight-Real-Estate.git
cd Delight-Real-Estate
```

2. Install dependencies:
```bash
pnpm install
# or
npm install
```

3. Run the development server:
```bash
pnpm dev
# or
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📜 Available Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Build for production
- `pnpm start` - Start production server
- `pnpm lint` - Run ESLint
